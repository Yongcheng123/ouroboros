# OUROBOROS

**一个每天重写自己的网站。**

网站只有一个文件：`index.html`。它不是手写的，是每天凌晨由 GitHub Actions 跑一次搜索之后，
从 `genome.json` 重新编译出来的。搜索找到更好的东西，网站就改写自己、提交、重新发布。

被优化的对象是**在线装箱问题**的一个启发式评分函数。这个选择是刻意的：它有一个
无法解释、无法辩解的评价指标 —— 用掉的箱子比理论下界多百分之几。

```
propose (不可信)  ->  verify (可信)  ->  select  ->  record  ->  render
```

这条流水线的不对称，就是整个项目想说清楚的那件事。

---

## 四层递归

| 层 | 在改什么 | 谁在改 |
|---|---|---|
| **L0** 目标层 | `score(i, r, g, k)` 决定每件物品进哪个箱子 | 引擎 |
| **L1** 搜索层 | 八个变异算子改写 L0 的表达式树，MAP-Elites 维持多样性 | 引擎 |
| **L2** 元层 | 按实测命中率重估算子权重、退火步长、算力预算；合成新的组合算子 | 引擎 |
| **L3** 叙述层 | 把基因组确定性地编译成 `index.html`，包括数字、表格、图和实验日志 | 引擎 |
| — | **引擎自身的源代码** | **人，走 PR** |

最后一行是这个项目的立场。不让引擎改自己的源码，不是因为做不到，
而是因为一旦做了，就没有一个不被它改写的地方能站着说话。

## 三折划分

| 折 | 实例数 | 权力 |
|---|---|---|
| 训练折 `train` | 8 | 驱动搜索。冠军必须在这里严格更优才有资格往下走。 |
| 验证折 `val` | 4 | **只有否决权。** 在训练折上赢了的候选，在这里一个箱子都不许多用，否则出局。 |
| 留出集 `test` | 12 | **什么权力都没有。** 不参与选择，不参与否决，只是被记录。故意做成最大的一折。 |

实例集由固定种子确定性生成，整套有一个指纹。引擎每次启动都会重算指纹，
对不上就拒绝继续进化 —— 换了考题的成绩单没有意义。

## 自己跑

零依赖，只要 Node 20 以上，不需要任何 API key。

```bash
node engine/evolve.mjs --date=2026-01-01 --generations=5
node tools/selfcheck.mjs
open index.html
```

### 命令

| 命令 | 作用 |
|---|---|
| `node engine/evolve.mjs` | 跑一代（默认用今天的日期） |
| `node engine/evolve.mjs --generations=10` | 连跑十代 |
| `node engine/evolve.mjs --evaluations=40000` | 覆盖本次评估预算 |
| `node engine/evolve.mjs --llm=true` | 同时让语言模型提候选（见下） |
| `node engine/evolve.mjs --reset` | 从第 0 代（Best Fit）重新开始，**会清空谱系** |
| `node engine/evolve.mjs --render-only` | 只重新渲染，不进化 |
| `node engine/render.mjs` | 同上 |
| `node tools/selfcheck.mjs` | 提交前的十一项检查 |
| `node tools/replay.mjs` | 用记录的种子重放最近一代，验证可复现 |

### 文件

| 文件 | 职责 |
|---|---|
| `genome.json` | 全部可进化状态：冠军表达式、精英档案、算子权重、σ、预算、里程碑、日志 |
| `history.json` | 只追加的世代记录 |
| `engine/expr.mjs` | 表达式树的语法、校验、编译、化简、渲染。**信任边界在这里** |
| `engine/problems.mjs` | 冻结的基准实例集。改这个文件等于作废全部历史 |
| `engine/benchmark.mjs` | 装箱器与打分。**唯一有裁决权的文件** |
| `engine/operators.mjs` | 八个变异算子与权重更新规则 |
| `engine/evolve.mjs` | 每晚的编排：验完整性 → 搜索 → 选择 → 自适应 → 记录 → 渲染 |
| `engine/render.mjs` | 基因组 → 网页。确定性，同样输入必须产出同样字节 |
| `engine/proposer-llm.mjs` | 可选。语言模型提议层 |
| `tools/selfcheck.mjs` | 发布前的门 |
| `tools/replay.mjs` | 重放验证 |

## 部署成一个每天自己进化的网站

1. **推到 GitHub。** 仓库必须是 public（除非有 GitHub Pro，Pages 才支持 private 仓库）。

2. **打开 Pages。** Settings → Pages → Build and deployment → Source 选 **GitHub Actions**。
   不要选 "Deploy from a branch"。

3. **给 Actions 写权限。** Settings → Actions → General → Workflow permissions
   选 **Read and write permissions**。没有这一步，每晚的自动提交会被拒绝。

4. **手动跑一次确认。** Actions → `evolve` → Run workflow。
   跑完之后 Actions → `pages` 里应该能看到部署好的地址。

之后每天 UTC 20:17（北京时间次日 04:17）会自动跑一代。
GitHub 的定时器是尽力而为，可能延迟几十分钟；引擎按日历日期记账，晚跑不影响正确性。

> **注意**：GitHub 会在仓库连续 60 天没有活动之后停用定时工作流。
> 这个项目每天自己提交，通常足以保持活跃；如果长期没人看，偶尔手动跑一次即可。

### 可选：把语言模型接进提议环节

```bash
npm install @anthropic-ai/sdk
export ANTHROPIC_API_KEY=sk-ant-...
node engine/evolve.mjs --llm=true
```

在 GitHub 上则是加一个 `ANTHROPIC_API_KEY` secret，手动触发 `evolve` 时把 `llm` 勾上。

模型会看到当前冠军、精英档案和最近日志，提出若干候选表达式。它们和变异算子产出的候选
走**完全相同**的一道关：语法白名单 → 编译 → 同一套实例集 → 同一个阈值 → 验证折否决。
模型不知道验收标准长什么样，也写不进基因组。一个胡编的、甚至恶意的建议，
和一个糟糕的变异在系统眼里没有区别 —— 都会在基准上输掉然后被丢弃。

**提议可以不可信，裁决必须可信。** 这是让一个无人值守、每天往仓库里提交代码的循环
可以被接受的唯一理由。

## 每晚实际执行的检查

`tools/selfcheck.mjs` 的十一项检查有任何一项不通过，当天就不提交、不发布：

1. **实例集指纹** — 重算全部物品的哈希，与基因组记录比对
2. **表达式语法白名单** — 冠军和全部精英只能由白名单里的算子和变量构成
3. **冠军完整性** — 重新评测已提交的冠军，三折得分必须一致到 1e-9
4. **世代记录只追加** — 世代号连续、日期不回退、无缺口
5. **训练折单调不升 / 验证折单调不升** — 选择压力和否决门每一代都生效
6. **算子权重** — 和为 1，且没有算子掉到 3% 地板以下（不许饿死任何思路）
7. **渲染确定性** — 重新渲染整页，与即将提交的文件逐字节比对
8. **页面自包含** — 无外部请求、无 `<script>`

`tools/replay.mjs` 更进一步：从上一个提交的基因组出发，用记录的种子重跑一遍，
必须落到完全相同的冠军。

## 这个项目不主张什么

它不会自己变得更聪明，不会跳出装箱问题，也不会重写自己的引擎。
它优化的是一个窄得不能再窄的东西，而且优化幅度会随着时间越来越小。

它主张的只有一件事：**"递归自我改进"要变成可以检验的工程对象，需要先把
提议权和裁决权分开，然后把裁决权锁在改写不到的地方。**
其余的部分 —— 每天的提交、曲线、日志 —— 都只是让这件事看得见。
